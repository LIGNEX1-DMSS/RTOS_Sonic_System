# RTOS_Sonic_System

## STM32 동작 개요

### 메인 루프 (while 문 내부)

`main()` 함수의 무한 루프(`while(1)`)에서는 다음과 같은 동작을 수행합니다:

- 약 500ms 간의 지연 후 (`HAL_Delay(500)`),
- `sensorA`와 `sensorB` 값을 `rand() % 100` 방식으로 시뮬레이션하여 생성
- 두 센서 값의 차이를 계산하여 `diff` 변수에 저장
- `"A:%d,B:%d,D:%d\r\n"` 형식의 문자열로 센서 데이터 포맷 생성
- 해당 문자열을 UART1을 통해 상위 장치(PC 등)에 전송

이 루프는 센서 데이터를 가상의 값으로 시뮬레이션하여 주기적으로 UART로 출력하는 테스트 구조입니다.

### UART 수신 인터럽트 (HAL_UART_RxCpltCallback)

STM32는 UART1을 통해 수신된 문자를 1바이트씩 처리하며, 인터럽트 기반의 명령 수신 및 응답 구조를 구현하고 있습니다.

#### 동작 흐름

- 수신한 바이트가 `\n`이면 명령어 한 줄 수신 완료로 간주
- 누적된 명령 문자열을 `strcmp`로 비교하여 다음과 같은 응답 지정:
  - `"A"` → `"ACK_A\n"`
  - `"B"` → `"ACK_B\n"`
  - 그 외 → `"ACK_N\n"`
- 응답은 `ackBuf`에 저장되며, `ack_ready` 플래그를 통해 메인 루프에서 송신
- 매 수신마다 인터럽트를 재등록 (`HAL_UART_Receive_IT`)하여 지속적인 수신 유지
- ISR 진입 시 LD3 핀을 토글하여 디버깅용 표시
